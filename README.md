## 🌸 Sobre o Jogo

**Lua e o Jardim dos Sonhos** é um jogo de plataforma 2D com foco em emoção, descoberta e atmosfera acolhedora. Criado como um presente pessoal e especial, o jogo conta a história de **Lua**, uma menininha que adormece e acorda em um jardim mágico cheio de criaturas gentis, flores que brilham e segredos escondidos.

> *Ela precisa encontrar o caminho de volta para casa — mas pelo caminho descobre que cada criatura do jardim guarda um presente especial para ela.*

Inspirado em **Child of Light**, **Valiant Hearts** e **Hollow Knight**, porém com foco total em encantamento, carinho e leveza — sem combates difíceis ou mecânicas complexas.

- 🎨 Estilo artístico desenhado à mão, inspirado em aquarela
- 🌈 Paleta de cores pastel quentes e vibrantes

## ⚙️ Mecânicas

O jogo foi projetado com apenas **3 ações** para ser acessível a qualquer criança:

| Ação | Controle | Descrição |
|---|---|---|
| 🏃 Andar | Setas ← → | Mover Lua pelo cenário |
| 🌟 Interagir | Tecla Z | Conversar com criaturas e regar flores |
| 🌸 Flutuar | Espaço (segurar) | Pulo mágico com levitação suave |

## 🎨 Direção Artística

- **Estilo:** Aquarela digital, traço à mão levemente trêmulo

## 🚀 Como Abrir o Projeto

1. Baixe e instale o [GDevelop 5](https://gdevelop.io/)
2. Clone este repositório:
   ```bash
   git clone https://github.com/SEU_USUARIO/lua-jardim-sonhos.git
   ```
3. Abra o GDevelop → **Abrir um projeto existente**
4. Navegue até a pasta clonada e selecione `LuaJardimSonhos.json`
